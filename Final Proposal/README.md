
# Final Project Proposal

## 1. Previous Assignment

For my final project, I mainly want to revisit my Week 9 Handpose project, Week 10 Sound Visualization project, and some elements from my Week 8 Self-Portrait project. These three assignments gave me different ideas, and I hope to combine them to create a more complete interactive experience or a small game. I want to use hand tracking technology as the main method of interaction.

## 2. Project Concept and Proposed Changes

For my final project, I want to create a small interactive game that combines gesture control, music visualization, and self-representation. Instead of mainly using a mouse or keyboard, players will interact with the game through hand gestures. The background will change with the music to create an immersive atmosphere. I may also include camera or self-portrait elements as a supporting visual layer. This project will combine different technologies in a more complex way and will also be more visually refined.
I am imagining a dreamlike or playful game world in which the player uses hand gestures to trigger actions, collect objects, or complete simple tasks. The music visualization in the background will help create rhythm, mood, and feedback during play.

## 3. Implementation and Challenges

To make this project, I plan to use p5.js as the main framework. I will likely use ml5.js handpose tracking for gesture interaction and sound analysis tools such as amplitude or FFT for the music-reactive background. I will need to combine several systems into one project: hand tracking input, game logic, visual animation, and audio response.

Some of the main challenges will be:
- making the hand tracking interaction stable and easy to understand
- combining gameplay and visual atmosphere in a clear way
- deciding how the self-portrait or camera layer should support the game
- balancing technical complexity with a project scope I can finish before the deadline

I will also need to learn more about structuring a larger p5.js project, organizing multiple interactive elements, and refining the game so it feels intentional rather than just combining different effects together.
