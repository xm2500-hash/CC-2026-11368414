# Week 11 — The Sky of My Hometown

## Concept

My hometown is Tianjin, China. Since I am currently living in New York, I wanted to create a weather visualization that allows me to see the sky of my hometown even when I am far away. 

## Data Source

I used the Open-Meteo API to obtain current weather data from Tianjin. I learned how to select weather variables, generate an API URL。
## Visual Design

I chose pink and purple as the main colors. I also recreated the Tianjin Eye Ferris wheel, a famous landmark in my hometown, along with the bridge, city buildings, and the Haihe River. These are all my favorite sights in my hometown.

- Temperature — Sky color
- Day and night — Sun, moon, stars, and city lights
- Cloud cover — Number of clouds
- Wind speed and direction — Cloud movement and water animation
- Rain and snowfall — Rain and snow particles
- Humidity — Fog transparency

I also added the distance between New York and Tianjin to make the project more personal.

## Process and Reflection

One of the challenges I faced was creating the shape of the clouds. At first, I used overlapping circles, but I did not like their appearance. I later used Bezier curves and gradient transparency to create softer clouds.
I used LLM to help me learn about Bezier curves and gradient transparency, and I have now mastered these techniques.
